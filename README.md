# Бизнес Пульс — отраслевые демонстрации

- [Клиника](https://balakhmatov.github.io/clinic-pulse/) — загрузка врачей, маршрутизация, денежный потенциал, массовые цели выдачи/визитов и адаптивные дневные планы.
- [Салон красоты](https://balakhmatov.github.io/clinic-pulse/salon/) — свободные окна в рублях, подбор клиентов, экономика услуг и рейтинг мастеров относительно планового темпа.

Подробные пользовательские инструкции с формулами, форматами Excel/CSV и сохранением JSON:

- [README клиники](docs/README_clinic.md)
- [README салона](docs/README_salon.md)

Статические приложения без авторизации и подключённых внешних интеграций. Данные текущей вкладки сбрасываются при обновлении. Полную сессию можно сохранить JSON; файлы читаются в браузере. Исходный business-pulse и его production/stage этим репозиторием не изменяются.

Денежные возможности оцениваются по ценам/вместимости и подписаны отдельно от фактической выручки. Дневной пересчёт не меняет цель периода. Пропущенные закрытые дни клиники не считаются нулевым фактом.

Запуск: статический HTTP-сервер с корнем репозитория. Проверки: `node --test core.test.mjs salon/core.test.mjs growth.test.mjs`.
